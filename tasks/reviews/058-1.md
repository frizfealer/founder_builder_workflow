  - It removes every quoted `-m`/`--message` argument before scanning, including double-quoted text where `$(...)` and backticks do run.

  - The regex also has no word boundary, so `x-m "..."` is removed too. A crafted quote mix such as `echo '-m "' ; git clean -fd ; echo '"'` hides the command.
