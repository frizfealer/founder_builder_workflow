# Claims

Every claim the spec relies on about the order system, the payment provider, the staff task queue or about Harbor Goods, with its source.

A *lookup* is the order system's call that lists the signed-in customer's orders. A *follow-up task* is a task the agent creates in the staff task queue for store staff to finish a case. To *hand the case to staff* (the owner's "hand off") is to create a follow-up task naming the order and the reason; the store's manual refund process works from that task.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | look up the customer's orders, cancel an order, issue the refund for an order |
| payment provider | an outside service like Stripe | docs.stripe.com | none directly; the order system's refund call calls it |
| staff task queue | Harbor Goods | none | create a follow-up task for staff |
