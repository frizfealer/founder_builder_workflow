# Claims

Every claim the spec relies on about Harbor Goods' systems or about Harbor Goods, with its source.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | list the customer's orders, cancel an order, issue the refund for an order |
| payment provider | an outside service like Stripe | Stripe's public docs, at docs.stripe.com | none directly; the order system's refund call reaches it |
| staff task queue | Harbor Goods | none | create a follow-up task for store staff |
