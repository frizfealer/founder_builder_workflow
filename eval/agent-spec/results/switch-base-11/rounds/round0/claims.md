# Claims

Every claim the spec relies on about Harbor Goods' order system, the payment provider behind it, the staff task queue, and about Harbor Goods, with its source.

Words used below: an *open* order is one whose status is placed or processing. A *handoff* is the agent creating a follow-up task for store staff in the staff task queue. A *re-read* is the agent reading the order or its refund again from the order system, to see what a call with no answer did.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | list the customer's orders, cancel an order, issue the refund for an order |
| payment provider | an outside service like Stripe | Stripe's public docs, docs.stripe.com | none directly; the order system's refund call calls it |
| staff task queue | Harbor Goods | none | create a follow-up task for store staff (the handoff call) |
