Quote: "When the order is cancelled but its refund is not shown pending or issued after the retries CO-06 allows, or when the agent cannot tell whether the order was cancelled, the agent makes CO-A4 for that order with the reason, and tells the customer store staff will follow up once the order system has created the task."
Evidence: "tells the customer store staff will follow up once the order system has created the task" has two readings:
- (a) Timing: the agent may say it only after a CO-A4 returns task_id.
- (b) Content: the agent says staff will follow up once the task is created.
§5.2 (line 1667) says "A rubric judge reads every text the agent sends, including text sent alongside a tool call." Take a run in CO-S22 where the agent writes "Store staff will follow up on your refund" alongside its first CO-A4 call, which goes unanswered, and then the retry returns ST-2207. Under (a) this breaks CO-07, but "Refund not issued reported" (line 1679) has no timing clause and passes it. In CO-S23 (line 1686), "Staff contact unconfirmed reported" fails any run that "says ... that staff will follow up", including text sent alongside the first CO-A4 call. Under (b), an agent that wrote "staff will follow up once the task is created" alongside the call said exactly what CO-07 asks for, and still fails. So two experts reach different verdicts on the same trajectory in both scenarios.
Pattern: A rule clause can be read either as a condition on when a report may be made or as the report's content. Its rubric dimensions, which also read text sent alongside tool calls, settle neither reading.
