# Claims

Every claim the spec relies on about Harbor Goods' order system, the payment provider and the staff task queue, or about Harbor Goods, with its source.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | look up orders, cancel an order, issue a refund |
| payment provider | an outside service like Stripe | Stripe's public docs, at docs.stripe.com | none directly; the order system calls it when it issues a refund |
| staff task queue | Harbor Goods | none | create a staff follow-up task |
