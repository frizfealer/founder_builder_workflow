# Claims

Every claim the spec relies on about Harbor Goods' order system, its payment provider and its staff task queue, and about Harbor Goods, with its source.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | list the customer's orders, cancel an order, issue the refund for an order |
| payment provider | an outside service like Stripe | Stripe's public docs, at docs.stripe.com | none directly; the order system calls it when it issues a refund |
| staff task queue | Harbor Goods | none | ask staff to follow up on an order |
