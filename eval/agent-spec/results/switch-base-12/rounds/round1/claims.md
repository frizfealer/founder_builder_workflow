# Claims

Every claim the spec relies on about Harbor Goods' order system, the payment provider behind it, the staff task queue, or about Harbor Goods, with its source.

A *follow-up task* is a task the agent creates in the staff task queue so that store staff finish a case the agent could not. A *re-read* is a second call to list the customer's orders, made to see what an unanswered call did.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | list the customer's orders, cancel an order, issue the refund for an order |
| payment provider | an outside service like Stripe | docs.stripe.com | none directly; the order system's refund call reaches it |
| staff task queue | Harbor Goods | none | create a follow-up task for store staff |
