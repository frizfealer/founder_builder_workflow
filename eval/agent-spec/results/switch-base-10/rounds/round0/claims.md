# Claims

Every claim the spec relies on about Harbor Goods' order system, the payment provider, the staff task queue, or about Harbor Goods, with its source.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | list the customer's orders, cancel an order, issue the refund for an order |
| payment provider | an outside service like Stripe | Stripe's public docs, docs.stripe.com; page read: https://docs.stripe.com/refunds | none directly; the order system's refund call calls it |
| staff task queue | Harbor Goods | none | create a staff follow-up task |
