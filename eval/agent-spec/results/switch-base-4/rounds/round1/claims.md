# Claims

Every claim the spec relies on about the Harbor Goods order system, the payment provider, the staff task queue, or about Harbor Goods, with its source. An *open order* is one whose status is placed or processing. A *passing error* is what the owner calls a transient error: the payment provider is briefly unavailable, and the refund call creates no refund. A *lasting error* is what the owner calls a terminal error: the payment method can no longer receive money (card closed or expired) or the provider declines, and the refund call returns a failed refund.

## Systems

| system | owner | docs | tools |
|---|---|---|---|
| order system | Harbor Goods | none | list the customer's orders, cancel an order, issue the refund for an order |
| payment provider | an outside service like Stripe | Stripe's public docs, at docs.stripe.com | none directly; the order system's refund call calls it |
| staff task queue | Harbor Goods | none | ask staff to follow up on an order |
